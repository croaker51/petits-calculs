# Petits Calculs

Application web (PWA) d'entraînement au raisonnement mathématique pour des enfants de CP.
HTML/CSS/JavaScript sans dépendance, fonctionne hors-ligne, installable sur iPhone
(Safari → Partager → « Sur l'écran d'accueil »).

- Aucune donnée ne quitte l'appareil : pas de compte, pas de statistiques, pas de publicité.
- Les prénoms et le code parent sont saisis sur l'appareil, jamais dans ce dépôt.
- Voix : fichiers audio pré-générés avec des voix neuronales libres (Piper / Kokoro via sherpa-onnx).

Historique des versions : voir `CHANGELOG.md`.
